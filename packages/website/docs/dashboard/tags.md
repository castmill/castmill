# Tags

Tags are coloured labels that you attach to media, playlists, channels and devices. Use them to find things quickly and to group resources by location, campaign, department or anything else that suits you.

## Tags and tag groups

- A **tag** has a name and a colour.
- A **tag group** collects related tags. It has a name, a colour and an icon.

For example, a "Locations" group can hold the tags "Lobby", "Cafeteria" and "Meeting room". Tags don't need a group; tags without one are listed under **Ungrouped**.

## Managing tags

Open **Tags** in the sidebar. The page lists **Ungrouped** tags and the **Tag Groups** with their tags.

| Task | How |
| --- | --- |
| Create a tag | Click **Create Tag**, enter the name, choose a colour and optionally a **Tag Group** |
| Create a group | Click **Add Group**, enter the name and choose a colour and icon |
| Edit a tag or group | Use **Edit Tag** or **Edit Group** |
| Delete a tag | Use **Delete Tag**. The tag is removed from all resources. |
| Delete a group | Use **Delete Group**. All tags in the group are deleted too. |

Creating, editing, deleting and assigning tags needs the Administrator or Manager role. Other roles see tags and can filter by them.

## Tagging resources

On the **Medias**, **Playlists**, **Channels** and **Devices** pages:

1. Click the tags cell of a row.
2. In the popover, select or clear the tags. Changes are saved immediately.
3. To create a tag on the spot, type its name in the search box and press Enter.

To tag several resources at once, select them with the checkboxes and click **Manage Tags** in the selection toolbar.

## Filtering by tags

Use the tag filter in the toolbar of a resource page and select one or more tags. Choose how they combine:

| Mode | Shows |
| --- | --- |
| **Any** | Resources with at least one of the selected tags |
| **All** | Only resources with every selected tag |

## Tree view

Resource pages can show their items as a tree instead of a table: tag groups at the top level, their tags below them, and the resources under each tag. A resource with several tags appears under each of them. Resources without tags are listed under **Untagged**.

## Limits

Your plan sets the maximum number of tags and tag groups. When you reach a limit, delete tags or groups you no longer use, or ask for a larger plan. See [Usage and quotas](./usage-and-quotas.md).
