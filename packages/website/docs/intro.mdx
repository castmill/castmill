# Castmill documentation

Castmill is an open-source digital signage platform. You manage content, schedules and screens from a web dashboard, and players on each screen download what they need and keep playing when the network is down. You can run Castmill on your own servers or use a hosted installation.

These pages cover every part of the platform, from uploading your first image to deploying a server and writing your own widgets.

## How Castmill works

Content reaches a screen in four steps:

1. **Upload** images and videos in [Media](./dashboard/media.md), or configure a [widget](./dashboard/widgets.md) such as weather, RSS news or a QR code.
2. **Arrange** them in a [playlist](./dashboard/playlists.md), where each item has a duration and a transition. A [layout](./dashboard/layouts.md) splits the screen into zones that each play their own playlist.
3. **Schedule** playlists on a [channel](./dashboard/channels.md). A channel is a weekly calendar with a default playlist for the times nothing else is scheduled.
4. **Play** the channel on one or more [devices](./dashboard/devices.md). Each device runs a Castmill player that caches the content locally.

Everything lives inside an [organization](./concepts/organizations.md). Organizations belong to a [network](./concepts/networks.md), which is the top-level tenant with its own domain, branding and plans. The [content model](./concepts/content-model.md) explains how these resources relate.

## Main features

| Area | What you get |
| --- | --- |
| Content | Image and video upload with automatic thumbnails and transcoding, playlists, multi-zone layouts and tags |
| Scheduling | Weekly channels with per-channel timezones, and [automations](./dashboard/automations.md) that interrupt programming at set times |
| Widgets | Built-in weather, RSS, stock ticker, QR code, web page and Spotify widgets, plus custom JSON [template widgets](./developers/widgets/overview.mdx) |
| Data | Token-protected [feeds](./dashboard/feeds.md) that let other systems push JSON to screens |
| Devices | Remote preview, telemetry, event logs, cache inspection, maintenance actions, power schedules and screen orientation |
| Players | Browser, Android, LG webOS (native and legacy), Electron for macOS and Linux |
| Access | Passkey sign-in, seven organization roles, teams, invitations and network-wide administration |
| Integrations | REST API, webhooks, an MCP server for [AI agents](./dashboard/ai-agents.md) and server [add-ons](./developers/addons.md) |

## Conventions in these pages

- Names of dashboard pages, buttons and fields are in **bold**, for example **Content → Playlists**.
- Commands and file names are in `code`.
- Notes marked **Tip**, **Note** and **Warning** contain practical advice, background information and risks of data loss, respectively.
