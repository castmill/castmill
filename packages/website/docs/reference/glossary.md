# Glossary

| Term | Meaning |
| --- | --- |
| **Addon** | An extension of the server and dashboard. Most dashboard pages are addons. See [Addons](../developers/addons.md). |
| **Admin tool** | The operator interface at `/admin` on the server, used to create networks and appoint network administrators. See [Admin tool](../administration/admin-tool.md). |
| **Agent** | An AI assistant that works in an organization through the MCP server, with its own role and secret. See [AI agents](../dashboard/ai-agents.md). |
| **Aspect ratio** | The width-to-height proportion of a playlist or layout, such as 16:9 for landscape or 9:16 for portrait screens. |
| **Automation** | A rule that interrupts normal playback with a playlist at set times on chosen devices or channels. See [Automations](../dashboard/automations.md). |
| **Channel** | A weekly schedule of playlists in one timezone, with a default playlist for unscheduled time. Devices play channels. See [Channels](../dashboard/channels.md). |
| **Channel entry** | One scheduled block in a channel's calendar: a playlist with a start, an end and an optional weekly repetition. |
| **Credentials** | API keys or OAuth tokens that a widget needs to fetch data from a third-party service. They are stored encrypted. |
| **Device** | A registered player, usually one screen. See [Devices](../dashboard/devices.md). |
| **Feed** | A collection of JSON data that external systems write to through the Feeds API and widgets display. See [Feeds](../dashboard/feeds.md). |
| **Layout** | A division of the screen into zones. A layout widget in a playlist plays one playlist in each zone. See [Layouts](../dashboard/layouts.md). |
| **Media** | An uploaded image or video, with its generated thumbnails and transcoded versions. See [Media](../dashboard/media.md). |
| **Network** | The top level of an installation: a dashboard domain with its own branding, plans, organizations and users. See [Networks](../concepts/networks.md). |
| **Network administrator** | A user who manages a network's settings, organizations, users and widget access from the dashboard. See [Network administration](../administration/network-administration.md). |
| **Organization** | A workspace that owns content, devices and members. Everything in the dashboard happens inside an organization. See [Organizations](../concepts/organizations.md). |
| **Passkey** | A credential stored on your device or password manager that replaces passwords for signing in. See [First sign-in](../getting-started/first-login.md). |
| **Pincode** | The registration code that a player shows until it is added to an organization. |
| **Plan** | A set of quotas assigned to organizations. See [Plans and quotas](../administration/plans-and-quotas.md). |
| **Player** | The application that runs on a screen and plays content: in a browser, or as an app for Android, webOS or Electron. See [Players](../players/overview.md). |
| **Playlist** | An ordered list of widgets, each with a duration, that plays in a loop. See [Playlists](../dashboard/playlists.md). |
| **Quota** | The maximum number of a resource, or amount of storage, that an organization can use. See [Usage and quotas](../dashboard/usage-and-quotas.md). |
| **Role** | A set of permissions that a member has in an organization, such as Administrator, Manager or Editor. See [Users and teams](../concepts/users-and-teams.md). |
| **Root user** | The account that signs in to the admin tool, configured with environment variables. |
| **Tag** | A coloured label for organizing and filtering resources. Tags belong to tag groups. See [Tags](../dashboard/tags.md). |
| **Team** | A group of members and resources within an organization. See [Teams](../dashboard/teams.md). |
| **Template widget** | A widget defined in JSON from components such as text, image, list and group, with options and data bound into it. See [Widget development](../developers/widgets/overview.mdx). |
| **Widget** | A building block that shows something on screen: an image, a video, a web page, a weather forecast, a news ticker or a custom template. |
| **Widget configuration** | The options and data of one widget inside one playlist item. |
